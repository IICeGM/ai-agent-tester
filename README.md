# GAME4U AI Agent UI/UX Tester 

Project นี้ทำเพิ่มมาจาก Game4u ซึ่งเป็น project ส่วนตัว 
โดยให้ playwright เข้าไปตาม url ของ website game4u เพื่อเเคปเเละรีวิว


ระบบทดสอบและประเมินผลหน้าจอผู้ใช้งานอัตโนมัติ (Automated UI/UX Evaluation System) สำหรับเว็บไซต์ **GAME4U** โดยใช้พลังของ **Multimodal AI (Gemini 2.0)** ร่วมกับสคริปต์ทดสอบเบราว์เซอร์ **(Playwright)** เพื่อจำลองพฤติกรรมผู้ใช้งานจริงแบบ Scenario-based

---

##  ฟีเจอร์เด่น (Key Features)

* **Persona-Driven Testing:** จำลองตัวตนผู้ใช้จริงที่มีนิสัยและเป้าหมายเฉพาะกลุ่ม (เช่น สายตามรอยสตรีมเมอร์) เพื่อตรวจเช็คความพึงพอใจของหน้าเว็บตามรสนิยมจริง
* **Automated Screenshot Capture:** ใช้ Playwright เปิดเบราว์เซอร์ วิ่งไปแคปภาพหน้าจอเวอร์ชันล่าสุดจาก Localhost อัตโนมัติ พร้อมระบบล้างไฟล์ภาพเก่า (Clean up) ก่อนเริ่มรันเสมอ
* **AI Multimodal Analysis:** ส่งภาพหน้าจอเข้า Gemini API เพื่อวิเคราะห์จุดติดขัด (Pain Points) จุดเด่น และให้คะแนน UI/UX ออกมาเป็นโครงสร้างข้อมูลที่นำไปใช้งานต่อได้ทันที
* **Smart Fallback Mode:** มีระบบรองรับความเสียหาย (Resilience) หากระบบภายนอกเกิดปัญหาขัดข้องหรือเกินโควต้า (เช่น Error 429) ระบบจะสลับมาเปิดโหมดจำลองข้อมูลคุณภาพสูงอัตโนมัติ ทำให้สคริปต์หลักทำงานจนจบเดดไลน์ได้โดยไม่พัง (Crash)

##  โครงสร้างโปรเจกต์ (Project Structure)

```text
ai-agent-tester/
├── data/
│   └── personas.js          #  STEP 1: ฐานข้อมูลจำลองตัวตนผู้ใช้ (Target Personas)
├── outputs/
│   └── persona_review_report.json #  STEP 4: ไฟล์รายงานผลลัพธ์เชิงลึกรูปแบบ JSON
├── .env                     #  ที่เก็บ API Key ของระบบเพื่อความปลอดภัยระดับ Production
├── execute_review.js        #  STEP 2 & 3: สคริปต์หลักควบคุมการทำงานของระบบทั้งหมด
├── game4u_review.png        #  ภาพถ่ายหน้าจอเว็บไซต์เวอร์ชันล่าสุดที่ถูกแคปออกมา
└── package.json             #  ตัวจัดการ Dependencies และ Libraries ของโปรเจกต์
🛠️ การติดตั้งและตั้งค่า (Installation & Setup)
ติดตั้ง Dependencies เข้ามาที่โฟลเดอร์ ai-agent-tester แล้วรันคำสั่ง:

Bash
npm install
(หรือติดตั้งด้วยตนเอง: npm install @google/generative-ai playwright dotenv)

ตั้งค่า Environment Variable สร้างไฟล์ชื่อ .env ไว้ที่ Root ของโฟลเดอร์นี้ แล้วระบุรหัสกุญแจ Gemini API ของคุณ:

ข้อมูลโค้ด
GEMINI_API_KEY="ใส่_API_KEY_ของคุณตรงนี้"
🏃‍♂️ วิธีการใช้งาน (How to Run)
เปิดรันระบบหน้าเว็บหลัก (GAME4U Web App) ของคุณทิ้งไว้ในเครื่องก่อน (เช่นพอร์ต http://localhost:5173/)

เปิด Terminal ในโฟลเดอร์เครื่องมือทดสอบนี้ แล้วสั่งรันคสั่ง:

Bash
node execute_review.js
